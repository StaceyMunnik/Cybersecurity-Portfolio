# Google Cybersecurity Professional Certificate

This repository documents my progress through the **Google Cybersecurity Professional Certificate** (Coursera), including course objectives, tools used, and hands-on practicals. The certificate consists of 9 courses covering foundational cybersecurity concepts through to job-readiness, and helps prepare graduates for the CompTIA Security+ exam.

##  Overview

| | |
|---|---|
| **Provider** | Google Career Certificates (via Coursera) |
| **Level** | Beginner — no prior experience required |

| **Focus areas** | Security frameworks, network security, Linux/SQL, threat detection, incident response, Python automation |
| **Target roles** | SOC Analyst, Cybersecurity Analyst, Security Analyst, IT Security Analyst |

##  Courses, Objectives & Tools

| # | Course | Learning Objectives | Tools & Skills |
|---|---|---|---|
| 1 | **Foundations of Cybersecurity** | Understand the role of a cybersecurity analyst; explain security ethics; identify how attacks impact business operations; learn the CISSP 8 security domains | CIA triad, security frameworks & controls, SIEM concepts |
| 2 | **Play It Safe: Manage Security Risks** | Identify threats, risks, and vulnerabilities to business operations; understand how organizations use frameworks/controls; use a playbook to respond to incidents | NIST, OWASP, risk management framework, SIEM tools |
| 3 | **Connect and Protect: Networks and Network Security** | Define network types and components; explain how data moves across a network; secure networks against intrusion; describe system hardening | TCP/IP, firewalls, VPNs, cloud network security, IDS/IPS |
| 4 | **Tools of the Trade: Linux and SQL** | Compare GUI vs CLI; navigate and manage file systems via Bash; use SQL to query databases | Linux, Bash, SQL, access control |
| 5 | **Assets, Threats, and Vulnerabilities** | Classify assets; analyze attack surfaces; identify threats (social engineering, malware, web-based exploits); summarize the threat modeling process | Threat modeling, CVEs, MITRE ATT&CK, asset inventory, cryptography |
| 6 | **Sound the Alarm: Detection and Response** | Contain, eradicate, and recover from an incident; analyze packets to interpret network traffic; understand IDS/NIDS signatures and logs; query SIEM tools to investigate events | Splunk, Chronicle, Suricata, Tcpdump/Wireshark, packet/log analysis |
| 7 | **Automate Cybersecurity Tasks with Python** | Explain Python's role in cybersecurity; write user-defined functions; use regular expressions to extract data; debug code | Python, regex, file I/O, log parsing, automation |
| 8 | **Put It to Work: Prepare for Cybersecurity Jobs** | Determine when/how to escalate an incident; engage with the cybersecurity community; apply AI tools to boost security workflows | Incident escalation, AI-assisted security workflows, technical communication |
| 9 | **Accelerate Your Job Search with AI** | Identify transferable skills and career paths; build a resume and job search plan; practice interviews using AI tools | Google Sheets, Gemini, prompt engineering, career planning |
