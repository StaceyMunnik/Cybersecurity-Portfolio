# Documenting Incidents with an Incident Handler's Journal

Course: Sound the Alarm: Detection and Response

Objective: Practice the documentation discipline required to track a security incident from detection through resolution.
Deliverable: A structured incident handler's journal entry covering detection, analysis, containment, eradication, and recovery for a simulated incident.
Outcome: Demonstrated the ability to maintain clear, chronological incident documentation — a skill directly tied to SOC analyst workflows and escalation processes.
Build: Completed incident handler's journal entry (Markdown/PDF) for a simulated incident.
Skills: Incident documentation, chronological reporting, escalation decision-making
Tools: SOC workflows, incident response playbook structure
