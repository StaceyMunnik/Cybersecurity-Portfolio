# Using Linux Commands to Manage File Permissions

Course: Tools of the Trade: Linux and SQL

Objective: Apply Linux file permission and access control principles to secure a file system against unauthorized access.
Deliverable: A documented set of Bash commands (chmod, chown, ls -l, etc.) with before/after permission states and rationale for each change.
Outcome: Demonstrated practical command-line proficiency in enforcing least-privilege access at the file-system level.
Build: Annotated command-line log/script showing permission changes and their justification.
Skills: Command-line proficiency, access control enforcement, least-privilege implementation
Tools: Linux, Bash
