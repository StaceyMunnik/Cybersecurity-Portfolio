# Conducting a Security Audit

Course: Play It Safe: Manage Security Risks

Objective: Assess a mock organization's security posture against established controls and identify gaps.
Deliverable: A completed audit checklist/report covering physical, technical, and administrative controls, mapped to a recognized framework.
Outcome: Identified control gaps and recommended remediations, demonstrating the ability to translate a framework into a practical assessment.
Build: Security audit report/checklist mapping observed controls to a compliance framework.
Skills: Risk assessment, control evaluation, audit documentation, compliance mapping
Tools: NIST, INFOSEC principles, CIA triad, risk management framework
