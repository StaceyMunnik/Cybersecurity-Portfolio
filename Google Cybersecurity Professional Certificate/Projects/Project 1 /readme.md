# Applying Filters to SQL Queries
Course: Tools of the Trade: Linux and SQL

Objective: Retrieve and isolate specific security-relevant records from a database using filtered SQL queries.
Deliverable: A set of annotated SQL queries (using WHERE, AND/OR, wildcards, etc.) demonstrating targeted data retrieval for an investigative scenario.
Outcome: Showed the ability to query databases efficiently to support an investigation — a core skill for triaging security-relevant data.
Build: Annotated .sql file with queries and sample output.
Skills: Database querying, data filtering, investigative triage
Tools: SQL, relational database querying
