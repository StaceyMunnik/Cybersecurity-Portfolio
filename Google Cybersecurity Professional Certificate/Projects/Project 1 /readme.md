# Applying Filters to SQL Queries
Course: Tools of the Trade: Linux and SQL

Objective: 
Retrieve and isolate specific security-relevant records from a database using filtered SQL queries. Apply Linux file permission and access control principles to secure a file system against unauthorized access.
Deliverable: A set of annotated SQL queries (using (WHERE), (AND)/(OR), wildcards, etc.) demonstrating targeted data retrieval for an investigative scenario.A documented set of Bash commands (chmod, chown, ls -l, etc.) with before/after permission states and rationale for each change.
Outcome: Showed the ability to query databases efficiently to support an investigation — a core skill for triaging security-relevant data.
Tools Used: SQL, relational database querying, access control concepts 
Outcome: Demonstrated practical command-line proficiency in enforcing least-privilege access at the file-system level. — a core skill for triaging security-relevant data.
Build: Annotated command-line log/script showing permission changes and their justification.
Skills: Command-line proficiency, access control enforcement, least-privilege implementation
Tools: Linux, Bash
