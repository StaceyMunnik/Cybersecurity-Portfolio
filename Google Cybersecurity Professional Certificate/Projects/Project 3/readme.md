# Analyzing Network Structure and Security

Course: Connect and Protect: Networks and Network Security

Objective: Evaluate a network's architecture to identify how data flows and where security controls should be applied.
Deliverable: A network diagram/analysis document identifying key components (routers, firewalls, segments) and the security measures protecting each.
Outcome: Demonstrated understanding of how to secure a network against common intrusion tactics and where hardening should be prioritized.
Build: Annotated network diagram and written architecture analysis.
Skills: Network mapping, security architecture review, intrusion prevention planning, system hardening
Tools: TCP/IP, firewalls, VPNs, cloud network security concepts
