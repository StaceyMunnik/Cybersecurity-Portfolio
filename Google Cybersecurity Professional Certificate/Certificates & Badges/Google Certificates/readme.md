
# Foundations of Cybersecurity
This module delivers a comprehensive overview of Course 1 and serves as a formal introduction to the security certificate program. It acquaints learners with the instructor, the Coursera platform, available content types, and established learning procedures, while also facilitating peer engagement among participants. The module defines the field of security, outlines the primary professional responsibilities of security practitioners, and emphasizes the core competencies required in the discipline. Additionally, Module 1 provides structured career guidance for learners seeking to pursue opportunities within the security field.

# Play It Safe: Manage Security Risks
This module provides a structured overview of the emergence and evolution of security threats in parallel with the widespread adoption of computers and the rapid expansion of the Internet. It examines how both historical and contemporary attacks have shaped and influenced the development of the security field as a discipline. Furthermore, the module offers a high-level introduction to the eight core security domains, establishing a foundational understanding of the broader security landscape.

# Connect and Protect: Networks and Network Security
This module presents a comprehensive overview of security frameworks and controls, with a focus on their application in mitigating organizational risk. It examines the CIA triad as a foundational model of information security, alongside an exploration of various National Institute of Standards and Technology (NIST) frameworks and their role in guiding security practices. The module further provides a detailed explanation of security ethics, underscoring the professional principles and responsibilities that govern conduct within the security field.

# Tools of the Trade: Linux and SQL
This course focused on building foundational technical skills essential to security operations, covering the Linux operating system and SQL for data querying. Key topics included navigating the Linux command line, managing files and directories, working with filesystem permissions, and using Bash scripting to automate routine security tasks. The course also introduced SQL fundamentals, including writing basic queries to filter, sort, and retrieve data — a core skill for investigating logs and databases during security analysis. # Assets, Threats, and Vulnerabilities
This course explored core risk management concepts in cybersecurity, focusing on how organizations identify, classify, and protect their assets while understanding the threats and vulnerabilities that put them at risk. Key topics included asset classification and the CIA triad (Confidentiality, Integrity, Availability), common attack vectors and threat actor types, vulnerability assessment, and the application of security frameworks and controls to reduce organizational risk, alongside foundational concepts in cryptography and encryption for protecting sensitive data.

# Sound the Alarm — Detection and Response
This course focused on the detection and response phase of the security lifecycle, exploring how security teams identify, investigate, and respond to threats within an organization. Key topics included the components and function of a Security Operations Center (SOC), the use of intrusion detection systems (IDS) and SIEM tools for monitoring and analyzing network activity, and the stages of incident response — from detection and containment to eradication and recovery. The course also covered log analysis and the application of playbooks to guide consistent, effective response to security incidents.

# Automate Cybersecurity Tasks with Python
This course focused on using Python to automate routine cybersecurity tasks and improve efficiency in security operations. Key topics included Python fundamentals such as variables, data types, conditionals, loops, functions, and string manipulation, alongside working with files, debugging code, and using regular expressions to search and parse data. The course also covered how these Python skills apply to real-world security use cases, including automating log analysis, filtering large datasets, and streamlining repetitive tasks to support more efficient threat detection and response.

# Prepare for Cybersecurity Jobs
This course focused on preparing for entry into the cybersecurity field, covering both technical readiness and the practical steps involved in the job search process. Key topics included incident response and how to communicate findings effectively, strategies for continuing professional development within cybersecurity, and guidance on building a resume, preparing for interviews, and engaging with professional networks. The course also emphasized how to position foundational cybersecurity skills and certifications to pursue entry-level roles such as Security Analyst.

# Accelerate Your Job Search with AI
This course focused on leveraging artificial intelligence tools to strengthen and streamline the cybersecurity job search process. Key topics included using AI to optimize resumes and cover letters, prepare for behavioral and technical interviews, and identify roles aligned with individual skills and career goals. The course also covered responsible and effective use of AI tools throughout the job application process, reinforcing how to present cybersecurity skills and certifications persuasively to prospective employers.
